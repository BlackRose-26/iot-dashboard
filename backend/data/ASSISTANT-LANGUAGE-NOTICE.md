# Bundled public language resources

`assistant-language-lexicon.json` contains filtered word forms, separated into `english` and `tagalog`, with source/asset provenance. It contains no example sentences, glosses, private records, model training labels or project test prompts. This resource supports lexical admission only; it supplies no system facts or authorization.

## English: Princeton WordNet 3.0

Citation: George A. Miller (1995), “WordNet: A Lexical Database for English,” Communications of the ACM 38(11), 39–41; Christiane Fellbaum (1998, ed.), *WordNet: An Electronic Lexical Database*. Source: <https://wordnet.princeton.edu/>.

Modifications: extracted bounded lowercase word forms, removed person/instance and uppercase/proper-name entries, discarded definitions/examples/relations, and sorted/deduplicated. Source archive SHA-256 is stored in the resource.
